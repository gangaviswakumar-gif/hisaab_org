Hisaab 

Offline-First Healthcare Assistant for ASHA Workers

Hisaabis an offline-first healthcare assistant designed to help ASHA workers record, manage, and follow up on patient information with minimal manual data entry.

 What It Does

* Voice-based data entry using Faster-Whisper
* Local AI extraction using Ollama
* Rule-based health-risk detection
* Offline patient & visit records using SQLite
* Follow-up tracking
* Tamper-evident records using a hash chain
* Patient history and information retrieval

How It Works

Voice Input
    ↓
Speech-to-Text
    ↓
Local AI Extraction
    ↓
Structured Health Record
    ↓
Risk Detection
    ↓
Offline Storage
    ↓
Hash Verification
    ↓
Follow-up Tracking


Healthcare Scope

Hisaab is designed around MCH/RCH workflows, including:

* Maternal health
* Pregnancy and antenatal care
* Postnatal care
* Child health
* Immunization
* Follow-ups and referrals

Why Hisaab?

Offline-first. Voice-first. Trust-focused.

Hisaab reduces manual data entry while allowing frontline health workers to continue recording and accessing essential information even with limited connectivity.

Future Scope

* Regional-language voice support
* Secure synchronization when internet is available
* Expanded MCH/RCH workflows
* Integration with existing healthcare systems
* Stronger authentication and encryption
